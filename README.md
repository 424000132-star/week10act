## Description
This Dart program demonstrates object-oriented programming concepts:
- **Mixin:** `Loggable` provides a reusable logging method.
- **Abstract class:** `Employee` defines shared employee information and the `calculatePay()` 

## How to Run
How to Run Open https://dartpad.dev/

```bash
dart run main.dart
```
